# dumbdns-rs — Document Index

dumbdns-rs answers DNS TXT queries with text from a language model.
It also stores small values through DNS UPDATE.

All documents use simple language. Each sentence has one idea.

- getting-started — first run plus seven use cases
- config — flags, environment, file order
- transports — UDP, TCP, DoT, DoH, DoQ, TLS, DNSSEC
- namespaces — names, sessions, memory beads, paging
- llm — model back ends, RAG, limits, breaker
- security — access control, abuse controls, threat model
- testing — checks and tests
